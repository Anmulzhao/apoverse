# APOVerse

A pixel art NFT game - summon, feed, and evolve your ghosts.

## 🎮 Game Mechanics

- **Summon**: Call your own pixel ghost NFT
- **Feed**: Keep your ghost happy to earn XP
- **Evolve**: Level up as you gain experience

## 🛠 Tech Stack

- Solidity 0.8.24
- Hardhat
- OpenZeppelin Contracts

## 🚀 Quick Start

```bash
npm install
npx hardhat compile
npx hardhat test
```

## 📜 Contracts

| Contract | Description |
|----------|-------------|
| `APOGhost.sol` | Main NFT contract for pixel ghost NFTs |

## 🎨 On-Chain Art

Every ghost has unique pixel art generated on-chain based on:
- Level (affects color)
- Generation
- Hunger status
